# 多语种翻译（1.0.4）

## 范围与操作

仅加入用户确定的 10 种语言，中文区分两个选项：`zh-Hans` 中文（简体）、`zh-Hant` 中文（繁体）、`en` 英语、`ja` 日语、`ko` 韩语、`fr` 法语、`de` 德语、`es` 西班牙语、`pt` 葡萄牙语、`ru` 俄语、`vi` 越南语。没有加入泰语或印尼语。

主页“翻译语言”中，输入译为、划词互译两侧、截图译为分别设置，点击“保存语言”后持久化。划词的两个选项必须不同；简体中文与繁体中文可组成语言对。交换按钮更换两侧顺序。快捷键、语言分别保存，未保存的控件编辑不会被运行状态刷新覆盖，未保存语言也会阻止升级重启。

默认输入译英语、划词简体中文与英语互译、截图译简体中文。旧 settings.json 不含这些属性时使用默认值；未知、空或重复的历史语言配置会恢复有效默认值，其他配置保留。保存无效语言对或写盘失败不改变当前生效的配置。

## 请求、结果与缓存

输入与截图将目标语言及简繁体要求放在 system 消息。原文保持原样作为 user 内容；截图提示读取所有可见语种，不再只识别英语。未改动模型别名、计费规则、输入候选读取机制或约 0.3 秒触发时机。

划词通过一次 DeepSeek 请求同时识别主要原文语言并翻译，不增加独立的语言分类请求。原文主要属于 A 时译 B，属于 B 时译 A；不属于两者或无法区分时译 A。除简繁语言对外，两种汉字书写形式均按语言对中的中文成员处理。简繁语言对直接辨认源脚本并转换，无法区分时转为 B。此规则由模型执行，短词、专名和混合文本可能判断不准。

划词返回 JSON 的 `target_language` 和 `translation`，校验目标必须是所选 A/B 之一、译文非空。格式不完整、语种代码错误或输出截断均报错，不作为成功译文展示或存入缓存。实际目标随结果一起进入缓存和浮窗，不再从原文重新猜测结果标签。

输入缓存版本为 `candidate-v2`，含目标语言；划词为 `selection-v3`，包含 A/B 的有序组合，缓存内容保留实际目标。不同语种、简繁体、交换左右后的回退规则及旧提示词结果不会混用。缓存仍只在本进程内存中保留，未持久化原文、译文或图片。

保存输入目标时，新设置与撤销旧候选／复制代次在同一个运行时锁中发布，旧请求取消，复制工作线程重新检查有效性；继续使用现有微软拼音观察服务，不重启服务或合成按键。保存划词语言对时撤销旧请求和浮窗，等待新的真实选区。已有截图固定使用请求发起时的目标，窗口按该目标标记结果。成功复制的剪贴板文本保持原状，仍需等新一轮“已复制”再粘贴。
