# 划词读取兼容修复（2026-11-06）

本轮暂停长句方案，修复“同样已经选中文字，有些输入框能翻译，网页或文档正文却没有反应”。沿用 DeepSeek 接口与现有拼音自动复制交互，不开发长句浮窗或修改微软拼音组字规则。

## 已确认的旧代码问题

旧 `SelectionMonitor` 把事件来源 RuntimeId 与当前键盘焦点 RuntimeId 必须相同作为入口条件，并只从 `AutomationElement.FocusedElement` 读取 TextPattern。网页、文档或阅读器的选择范围可能由 Document 或祖先节点公开，而键盘焦点留在子节点、链接或容器，导致真实选区被拒绝。全局后台事件又会先撤销当前代次，焦点变化仅撤销而没有重新调度；只等待事件也无法覆盖漏发事件的控件。旧实现还直接拒绝多个真实选区。

微软官方示例从 Document 查找 TextPattern 并读取 GetSelection，未要求提供者等于键盘焦点；官方事件说明也要求客户端复核实际状态，事件并不总对应真实变化：

- [通过 UI Automation 获取文本范围](https://learn.microsoft.com/en-us/dotnet/framework/ui-automation/obtain-text-attributes-using-ui-automation)
- [UI Automation 事件概述](https://learn.microsoft.com/en-us/dotnet/framework/ui-automation/ui-automation-events-overview)
- [EM_GETSEL 原生只读选区消息](https://learn.microsoft.com/en-us/windows/win32/controls/em-getsel)

## 修复方向

- 使用 UIA3，从前台有效的事件来源、当前焦点及祖先、鼠标下节点及祖先、受限的前台文档树查找真实选区，不以“可编辑”或“必须获得键盘焦点”为前提。
- 补上鼠标和键盘选择活动检测，以及去重的后台检查；无选区时不翻译整个页面，选区未变时不反复发 API 请求。
- 对缺少 TextPattern 的标准 Unicode Edit / RichEdit 控件，使用带超时的原生只读文本及选区消息；不发送 Ctrl+C，不改选区，不修改剪贴板或目标内容。
- 保留模式、输入活动、前台根窗口和选区范围校验。旧结果在新选择、关闭模式、暂停或失焦后不得显示；多个实际选区按顺序处理，空光标范围不冒充选区。
- 应用层在翻译前、翻译后和结果展示时都核对当前状态；增加翻译中的状态提示，并让取消操作的外部回调在应用锁外完成。
- 重复选区事件不会反复撤销同一请求，后台事件不会无限延后读取。输入活动在原生通知入口推进版本；只有已处理到该版本的读取才能发布，避免新动作仍在排队时把旧选区当成新结果。截图暂停后的旧事件、旧手势松手、提供者重建不会直接解开新选区屏障。
- UIA 明确报告不支持 TextPattern 时识别正确的 `UIA_E_NOTSUPPORTED` 错误码并进入原生读取；多段重复范围去重，异常交叠范围拒绝。密码或自身窗口的节点不会通过攀升祖先绕到其他旧选区。
- 完成选择动作后若未能读取到文字，状态栏提供一次温和提示；普通后台检查不重复刷提示，也不把空光标误判为翻译失败。
- 若鼠标松开后提供者稍晚才更新选区且不发事件，后台检查仍保留同前台根窗口的鼠标目标来恢复读取；目标完全不可读时不会转而翻译旧地址栏。新增的延迟更新回归先在修复前复现失败，再通过同一算法验证修复。

## 测试边界

用户本轮明确禁止控制电脑测试。因此只运行注入假的选区读取器、假的活动来源、合成文本树、假的 Win32 消息接口、假的翻译器及展示回调的测试；不构造真实 UIA 自动化实例，不安装真实全局钩子，不读取实际选区或剪贴板，不发送鼠标键盘输入，不启动测试窗口或产品窗口，不调用真实翻译 API。已有其他测试仍可进行临时文件及假密钥 DPAPI 往返。

`dotnet build src/PinyinTranslate.App/PinyinTranslate.App.csproj -c Release` 集成编译通过。`./scripts/test.ps1 -HeadlessOnly` 首轮 378 项全部通过；随后清理两处编译空值警告和两处测试分析提示，并新增延迟选区恢复及不可读目标隔离两项回归。最终复跑受影响的 Selection 与 App 测试；连同未改动且已通过的 Core，最终覆盖 380 项，编译输出无警告。

Headless 清单共审计 28 份测试及辅助源文件，排除一个可能读取外部真实测试凭据的可选方法；该方法不在以上运行数量中。本轮没有读取生产密钥，没有发出真实翻译请求。UIA3 遍历使用节点数与时间预算，并设置连接和事务超时；实际外部提供者行为仍需未来在允许桌面验证时评估。

发行目标：`artifacts/PinyinTranslate-selection-fix-win-x64.zip`，Windows x64、.NET 10.0.14 自包含免安装。使用不同目录发布，保留此前自动复制版；没有关闭或重启用户正在运行的程序。解压后先自行退出旧版，再启动新目录中的 `PinyinTranslate.App.exe`。

## 可用范围

此修复扩大可访问选区的读取范围，不能把所有应用都变成公开选区的文本控件。密码、权限隔离或受保护内容不会绕过；图片、扫描页和完全自绘且不公开选区的界面仍需要截图翻译。选区总长度保持 4000 个 UTF-16 单元上限，超限不截断发送。真实桌面兼容性未在本轮验证，不能把模拟通过宣称为所有软件实机通过。
