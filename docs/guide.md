# 使用与开发说明

返回 [项目首页](../README.md)。本文保留详细操作、兼容性与开发说明，命令和路径均以仓库根目录为准。

Windows 11 x64 中文桌面翻译工具，使用系统微软拼音。开启拼音翻译模式后，自动将当前页第一个中文候选翻译为所选目标语言（默认英语），在候选框上方预览，并将最新有效译文复制到系统剪贴板。等浮窗显示“已复制”，手动按 Esc 取消尚未上屏的拼音，再按 Ctrl+V 粘贴。程序不再拦截 Tab，也不自动取消拼音或向输入框发送按键。使用新版前应退出旧版，避免两个版本同时监听快捷键和输入。

触发时间沿用原实现：候选稳定约 100 毫秒，缓存未命中后再防抖 200 毫秒，然后请求接口，合计约 0.3 秒；网络和模型返回需要额外时间。缓存命中会更快。继续输入、改变候选、移动位置、切换焦点或关闭模式，会使旧一轮失效；迟到结果不会再作为当前结果复制。剪贴板写入会短暂重试，失败时明确提示。

自动复制会覆盖原剪贴板内容，并持续保留译文，不在 Esc、粘贴完成或模式关闭后恢复旧内容。下一轮成功翻译或你自己复制其他内容，会再次更新剪贴板。Win+V 是否保存记录还取决于 Windows 的剪贴板历史设置；程序不修改该设置。复制成功后不需要等待 Win+V，直接使用 Ctrl+V。

多语种与任意语言对互译见 [多语种说明](../reports/multilingual.md)。之前的中英划词双向翻译、等待状态修复见 `reports/selection-bidirectional.md`，其中本机中英方向判断已由当前的一次模型请求内自动识别取代；此前的选区兼容改进见 `reports/selection-fix.md`，拼音自动复制细节见 `reports/auto-copy.md`。本轮按用户要求，只用纯 fake 与合成快照做 headless 测试，不控制桌面、不访问真实系统剪贴板、不启动产品窗口、不调用付费 API。其他 `reports/ime-*.md`、`universal-input.md` 与 `tab-paste-fix.md` 保存历史版本的验证和限制，涉及 Tab 自动写入的说明不适用于当前默认流程。

## 启动

从 [GitHub Releases](https://github.com/ihhhhhooo/trans/releases/latest) 下载 `PinyinTranslate.Desktop-win-x64-Setup.exe`，双击即可安装并启动，无须手动解压。以后使用桌面或开始菜单的 PinyinTranslate 快捷方式打开。默认安装目录为当前账户的 `%LOCALAPPDATA%\PinyinTranslate.Desktop`。

也可下载 `Portable.zip`，解压到可写目录，运行 ZIP 根目录的 `PinyinTranslate.exe`。便携版请保留整个目录，包括 `current`、`Update.exe` 和 `.portable` 等配套文件。两种发行包均为 win-x64 .NET 10 自包含，不需要另外安装 .NET。首次运行，划词和拼音模式均关闭。请在左侧“设置”中填入自己的 DeepSeek API Key 并保存；密钥通过 Windows DPAPI CurrentUser 保存在当前用户的 `%LOCALAPPDATA%\PinyinTranslate\secrets`，不在发行包中。重新打开设置时，已保存的密钥会以掩码形式显示；修改后需再次点击“保存密钥”。此软件独立于 Codex 配置。

旧版普通解压包没有自动更新组件。首次迁移需退出旧版，运行新版 `Setup.exe`，或将便携 ZIP 完整解压一次；请勿覆盖正在运行的旧目录。使用同一 Windows 账户启动后会沿用原来的密钥、设置和统计。从 1.0.0 开始，在“设置 → 软件更新”中点击“检查更新”，有新版时下载，再点击“更新并重启”。1.0.0 便携版可直接通过此入口升级到新版，仍保持便携版形式；安装版与便携版之间切换时才需手动运行安装包或解压。检查和下载不会自行退出或安装，也无需 GitHub 令牌。详细说明见 [更新机制](../reports/updates.md)。

使用左侧栏在“翻译”“统计”和“设置”之间切换。在“设置”的界面风格中左右拖动、使用滚轮或箭头浏览极简风、波普风、漫画风、剪纸拼贴风和黑金鎏金风；点击风格卡片立即应用并保存，无须重启。各功能的快捷键和开关位于同一行；编辑快捷键后点击“保存快捷键”。

主页“翻译语言”提供中文（简体／繁体）、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、越南语，共 10 种语言、11 个选项。输入与截图各自选择目标语言；划词选择任意两种不同语言自动互译，可交换左右位置。修改后点击“保存语言”，无需重启。默认输入译英语、划词简体中文与英语互译、截图译简体中文；旧设置会沿用这些默认值，快捷键、风格、密钥与已有统计保留。

“设置”中可开启或关闭“开机自启动”，开启后会为当前 Windows 用户添加启动项，在登录该账户后启动程序。安装版和便携版的启动项均指向各自根目录启动器。首次迁移时，仅当原启动项已开启且可确认是本程序命令时，将它改为新路径；不会自动开启自启动。不认识的自定义命令保留原样，可关闭后重新开启，使其指向当前版本。

漫画风采用蓝黄撞色、网点和漫画描边；风格切换会更新主界面、设置与统计页，以及当前已打开的翻译结果窗口。

“统计”展示划词与截图的译文次数、原文和译文字符，以及结果复制次数、请求次数、输入输出 Token、估算费用和今日用量。复制次数包含拼音译文自动复制；API 用量也包含候选翻译请求。“复制统计”只复制汇总摘要。数据从显示的统计开始时间持续累计，软件升级会保留已有统计。字符包含空格和标点，截图字数根据识别文本统计。费用按 Flash 的缓存命中/未命中和北京时间高峰/空闲规则估算；缺少时段或缓存明细的历史估算单独显示，不与按缓存和时段计算的费用合并。不包含未返回用量的请求，实际费用以服务商账单为准。

- `Ctrl+Alt+D` 切换划词。模型在同一次翻译请求内识别主要原文语言，在所选语言对之间互译，例如英语与韩语、法语与德语；结果标明实际目标语言，不增加单独的识别请求。原文不属于两者或无法可靠区分时，默认译为左侧语言；简繁互译无法区分时默认转为右侧。短词、专名和混合语言的方向可能有歧义。可读取输入框、网页与文档的真实文本选区，选区提供者可以是文档或祖先节点，无须等于键盘焦点。鼠标划选、双击选词、键盘选择与选区事件都能触发读取，并用后台检查补漏。标准 Windows 文本框缺少 TextPattern 时尝试原生只读选区接口。选择的原文会发送给 DeepSeek；关闭模式或选区变化后丢弃在途结果。点击浮窗中的原文或译文即可复制。
- `Ctrl+Alt+S` 或点击按钮框选截图，Esc 取消。截图发送 DeepSeek，自动识别图中文字的语言并译为所选目标；结果窗保留原图，右侧提供对照、滚动和复制，点击每组原文或译文即可复制该行。已打开的截图固定使用本轮发起时的目标语言，后续修改不会误改结果标签。请核对原图：识别与分组可能遗漏或出错，多屏混合 DPI 未验证。
- `Ctrl+Alt+T` 独立切换微软拼音翻译模式。开启后开始新一轮拼音，候选上方自动预览所选语言的一个译法。浮窗区分“正在翻译”“正在复制”“已复制”和失败状态。等“已复制”后，手动 Esc → Ctrl+V。Esc 只取消尚未上屏的拼音，已经用空格或数字键上屏的中文不会被自动替换。
- Tab 及其组合键保持系统和当前软件原来的作用，包括微软拼音可能显示的必应建议。拼音复制功能不要求输入框支持自动写入，但仍需能够识别当前焦点和微软拼音候选。它不能绕过输入框自身的粘贴限制。

默认请求目标为 `deepseek-flash`、关闭思考模式。2026-11-05 官方文档映射至 DeepSeek-V4.1-Flash-1017，但此别名不保证永久固定。请求失败、鉴权失败或网络不可用时查看主界面状态或截图结果窗口。

划词和拼音候选的短期缓存仅驻留本进程内存，默认最多 128 条、保留 10 分钟，退出后清除；重复请求会合并。持续输入会取消旧一轮，但已到达服务商的请求仍可能计费。截图期间暂停划词监听，恢复后等待新的选区事件。

缓存区分输入目标语言、划词语言对及左右顺序、简繁体和提示词版本。保存新的输入目标会撤销旧候选预览和待复制任务；保存新的划词语言对会取消旧请求、关闭旧结果并等待重新选中文字。已成功复制的内容仍保留，请等新一轮“已复制”后再粘贴。

## 费用与本机数据

日常使用不设软件内请求次数或费用上限，使用用户自己的 API Key；服务商的账户状态和计费规则仍然适用。新版 `%LOCALAPPDATA%\PinyinTranslate\api-usage.json` 与 `usage-statistics.json` 只保存汇总计数，不保存翻译原文、译文、截图或密钥；统计同时读取旧版 `api-budget.json` 中可用的历史用量。

Flash 单价为人民币 / 百万 Token：空闲时输入缓存命中 0.02 元、未命中 1 元、输出 4 元，高峰分别为 0.04、2、8 元。高峰按北京时间周一至周五（不含中国法定节假日）09:00–12:00、14:00–18:00，区间含起点、不含终点；周末即使补班也按空闲价。内置已公布的 2026、2027 年放假区间，不依赖系统设置的时区。来源和验证见 [价格统计说明](../reports/pricing.md)。

按请求发起时段结算本地估算，完成时间跨入另一时段不改变该次价格。API 返回的 `prompt_cache_hit_tokens`、`prompt_cache_miss_tokens`（或兼容的缓存字段）用于拆分输入费用；这与软件本地译文缓存不同，本地缓存命中不发送 API 请求。缓存明细缺失时按未命中价作上限估算并标明；未来未覆盖年份的工作日高峰窗口也会标明日历不完整，不假造未来节假日。

旧版用量迁移后，请求和 Token 汇总保留；旧费用另列，因缺少缓存与具体时段数据不能准确重算。首次保存新格式时，原文件备份为 `api-usage.json.v1-backup.json`，已有备份不覆盖；损坏的历史文件不会被空统计替换。新格式仅在请求进行期间保存请求时刻用于计费，完成后只保留每日汇总。统计页“今日”按北京时间统计新增记录，旧汇总日期沿用原记录。

本次开发任务的付费测试预算仍单独保留在原 `api-budget.json`，供开发测试工具共用：累计 1 元人民币、最多 200 次推理请求尝试。正式软件的日常请求不写入该测试账本，也不受其限额约束。不要删除或修改测试账本以绕过任务预算。价格或模型映射改变时应先复核实现。

## 构建和测试

需要 .NET 10 SDK 与 Windows 桌面开发环境。在仓库根目录 PowerShell 中运行：

```powershell
./scripts/test.ps1 -HeadlessOnly
./scripts/package.ps1
./scripts/package.ps1 -Velopack
```

脚本使用 `Directory.Build.props` 固定的 .NET 10.0.14 win-x64 自包含发布，不启用裁剪或 Native AOT。默认输出普通目录与 ZIP；`-Velopack` 生成可自动更新的 EXE 安装版、便携 ZIP、完整更新包与发布索引。版本号统一在 `Directory.Build.props` 修改。将变更提交并推送后，推送与版本一致的 `vX.Y.Z` 标签，GitHub Actions 会运行 headless 测试、打包并发布到本仓库 Releases；不要覆盖已发布版本，修复应递增版本号。真实付费开发测试通过项目测试工具和同一测试预算账本；测试凭据不会打包。`reports/api-budget.json` 是早前交付时的只读快照，开发测试计数以本机 LocalAppData 测试账本为准，正式使用量单独保存在 `api-usage.json`。

`-HeadlessOnly` 会核对已静态审查的测试源码清单，新增未知测试文件时先报错。测试使用内存状态、合成 UIA 快照、虚拟剪贴板/键盘、临时文件和假密钥；不创建真实 UIA/全局钩子、不访问系统剪贴板、不发送输入或启动产品窗口，并明确排除读取外部真实凭据的可选测试。本轮结果见 `reports/selection-fix.md`；真实 Windows 输入兼容性没有在本轮验证。保留的旧 Tab 写入测试只覆盖历史路径，正式程序默认使用自动复制流程。

## 限制与排查

- 输入翻译需要目标控件公开可辨认的非密码焦点，以及当前微软拼音首候选。复制译文不要求完整正文、写入接口或可恢复的组合基线；候选无法读取时仍无法翻译，不保证所有软件兼容。
- 候选服务启动或运行失败时，状态提示区区分权限不足、配套文件缺失、启动超时、UIA 初始化失败、连接中断等原因，并显示阶段与错误代码；对当前控件按 1、2、4、8、15 秒间隔重试。只要具备候选预览能力就可启动服务，写入能力单独判断。整个包的主程序与候选服务必须来自同一个版本。
- 自动复制使用独立的 Unicode 文本写入路径，不读取或备份原有格式，也不走旧版粘贴/Unicode 按键回退。复制失败不会伪报“已复制”，不会自动清理拼音。请先等成功提示再按 Esc；若提前 Esc，本轮请求会取消，剪贴板可能仍是上一段内容。
- 剪贴板是系统共享资源。每个有效的新结果都会覆盖它；复制成功之后，你或其他软件再次复制的内容不会被本程序自动恢复为译文。跨进程焦点变化与系统剪贴板写入不是原子事务，写入前后均检查本轮是否仍有效，但不能对任意外部程序作绝对保证。
- 不支持的编辑器、高权限目标、混合 DPI、多屏及干净机器尚未完成广泛验证。按照本次要求没有操作 Edge，也未验证其兼容性。
- 划词使用真实选区接口；不会把控件标题、整页正文或完整输入框内容冒充选中文字，也不自动向目标发送 Ctrl+C。密码框、受保护或无法读取的高权限目标会被跳过。多段真实选区按顺序组合，总长度上限 4000 个 UTF-16 单元，超限会提示而不截断发送。图片、扫描页或完全不公开文本选区的自绘界面仍需截图翻译；不能保证所有应用兼容。
- 划词后台检查会去重，持续选中同一段不会按检查频率反复请求接口。同文出现在不同位置、切换选区、取消选择、关闭模式和截图暂停都会分别处理；显示结果前仍核对当前前台窗口、实际选区和输入活动。点击本软件结果中的复制行不会先撤掉结果窗口。
- 划词状态区分“正在确认选中文字”“正在翻译”“译文已返回，正在确认选区”和终态。接口最多等待 20 秒，实际选区监控的每轮复核最多等待 2 秒；超时会结束本轮并提示重新划选。等待上限不代表承诺网络或页面能在该时间内成功返回，底层不响应的页面调用也不能被安全强制终止。软件不会自动重复提交超时的接口请求；再次划选可重试，已经到达服务商的请求仍可能计费。
- 如果快捷键被占用，请换一组修饰键并保存；如果密钥或网络失败，检查密钥、服务状态和账户情况。关闭应用会释放快捷键。
- 开启拼音模式会将当前首候选发送给 DeepSeek；用于识别输入状态的信息只在本机处理。划词和截图请求分别发送选中文字、截图。输入译文自动进入剪贴板，划词和截图结果可在窗口中复制。

## 工程状态

当前采用 WPF、手写 P/Invoke、Windows UI Automation 3、FlaUI.UIA3 和 xUnit。候选由独立后台程序 `PinyinTranslate.ImeBridge.exe` 读取，通过本机当前用户管道与主程序通信；请保留发行目录中的全部配套文件。尚未接入最初指定的 CommunityToolkit.Mvvm 与 CsWin32。真实桌面和质量测试覆盖范围见报告。
