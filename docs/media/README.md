# 图片与视频位置

返回 [中文首页](../../README.md) / [English README](../../README.en.md)。两版首页均预留 1 个视频位和 3 个截图位，当前显示“待上传”占位图；英文占位 SVG 使用 `.en.svg` 后缀。

## 替换截图

将真实截图放在本目录，建议使用以下文件名：

| 展示位置 | 建议文件名 |
| --- | --- |
| 微软拼音候选预览与自动复制 | `input.png` |
| 划词翻译浮窗与语言方向 | `selection.png` |
| 截图翻译的原图与逐段对照 | `screenshot.png` |

然后同时修改仓库根目录 `README.md` 和 `README.en.md` 中的对应图片路径。真实截图可以由两种语言共用，例如：

```markdown
![输入翻译](docs/media/input.png)
![划词互译](docs/media/selection.png)
![截图对照](docs/media/screenshot.png)
```

替换完成后，可以移除“演示素材待补充”这句话。不用的占位 SVG 可以保留，或在所有引用移除后删除。

## 添加视频

上传或托管演示视频并取得可访问的地址，然后将两版首页的视频占位图替换为链接：

```markdown
[观看使用演示](替换为实际视频地址)
```

也可以放一张真实视频封面，点击封面打开视频：

```markdown
[![观看使用演示](docs/media/demo-cover.png)](替换为实际视频地址)
```

视频文件建议使用上传后的外部地址，避免把大体积视频加入源码仓库。建议演示“保存 API Key → 选择语言 → 输入／划词／截图翻译”，录制时隐藏真实密钥和个人内容。
